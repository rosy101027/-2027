# 대한민국 하천 범람 위험 지도 (학습용 프로토타입)

## 1. GitHub에 올릴 파일
아래 구조를 그대로 유지하세요.

```text
korea_river_flood_map/
├── app.py
├── requirements.txt
├── README.md
└── data/
    └── river_coefficients.csv
```

## 2. GitHub에 업로드
1. GitHub에서 새 저장소(Repository)를 만듭니다.
2. 위 파일과 `data` 폴더를 업로드합니다.
3. `Commit changes`를 누릅니다.

## 3. 웹사이트 배포
1. https://share.streamlit.io/ 에 접속해 GitHub 계정으로 로그인합니다.
2. `Create app`을 누릅니다.
3. 저장소, 브랜치(`main`), 메인 파일(`app.py`)을 선택합니다.
4. `Deploy`를 누릅니다.

## 4. 하천 자료 CSV 형식
`data/river_coefficients.csv`에는 다음 열이 있어야 합니다.

- `river_name`: 하천 이름
- `region`: 시·도 또는 시·군·구
- `lat`: 지도 위도
- `lon`: 지도 경도
- `bed_coefficient`: 공식 자료에서 확인한 하상계수
- `source`: 자료 출처 URL 또는 문서명

현재 CSV는 예시 형식만 제공합니다. 실제 하천 전체 목록과 하상계수 자료가 자동으로 완성되어 있는 것은 아닙니다. 공식 자료를 확인해 행을 추가해야 합니다. 확인되지 않은 하상계수를 임의로 입력하지 마세요.

## 5. 중요한 한계
- 하상계수는 하천의 계절별 유량 변동 특성을 나타내는 지표이며, 이것만으로 범람 확률을 계산할 수 없습니다.
- 강수량과 하상계수만으로 계산한 점수는 실제 범람 확률이 아닙니다.
- 이 프로그램의 지도 점수는 작동 예시를 보여 주는 단순 참고 지수입니다.
- 실제 홍수 예측에는 수위·유량, 하천 단면, 제방 높이, 유역 면적, 토양 포화도, 상류 강우, 댐 방류, 과거 홍수 자료 및 검증된 예측 모델 등이 필요합니다.
- 대피나 안전 판단에는 기상청·홍수통제소 등 공식 경보를 확인하세요.

## 6. 하천 이름 검색
검색창은 OpenStreetMap Nominatim을 사용해 검색 위치로 지도를 이동합니다. 외부 서비스 상태와 네트워크에 따라 검색 결과가 달라질 수 있습니다.
